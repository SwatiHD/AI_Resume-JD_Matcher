# AI Resume JD Matcher

AI-powered web application that analyzes resumes against job descriptions and provides ATS-focused optimization suggestions.

## Overview
This project helps job seekers compare their resumes with job descriptions, identify missing keywords, and receive AI-generated improvement suggestions to improve ATS compatibility.

## Features
- Resume upload
- Job description input
- ATS match score analysis
- Missing keyword detection
- AI-powered resume suggestions
- Responsive user interface

## Tech Stack
- React
- JavaScript
- Node.js
- Express.js
- Axios
- OpenAI API
